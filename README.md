# My Home Page 🏠

This is a personal homepage project built with Nuxt 3, Vue 3, and Element Plus. It showcases personal information, projects, skills, and blog posts.

[中文 README](README.zh-CN.md) 📖

## Setup 📦

Make sure to install the dependencies:

```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install

# bun
bun install
```

## Development Server 👨‍💻

Start the development server on `http://localhost:3000`:

```bash
# npm
npm run dev

# pnpm
pnpm run dev

# yarn
yarn dev

# bun
bun run dev
```

## Production 🚀

Build the application for production:

```bash
# npm
npm run build

# pnpm
pnpm run build

# yarn
yarn build

# bun
bun run build
```

Locally preview production build:

```bash
# npm
npm run preview

# pnpm
pnpm run preview

# yarn
yarn preview

# bun
bun run preview
```

## Development with OpenSpec 🚀

This project uses OpenSpec for documentation and development workflow. When working with agents, use the `openspec-propose` skill to enjoy the SDD (Specification-Driven Development) workflow:

- **Propose changes**: Use the `openspec-propose` skill in conversations with agents
- **Follow the workflow**: Agents will guide you through the specification-driven development process
- **Ensure quality**: OpenSpec helps maintain clear documentation and structured development

Check out the [OpenSpec documentation](https://openspec.dev) for more information.
