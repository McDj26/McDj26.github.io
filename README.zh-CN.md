# 个人主页 🏠

这是一个使用 Nuxt 3、Vue 3 和 Element Plus 构建的个人主页项目。它展示个人信息、项目、技能和博客文章。

[English README](README.md) 📖

## 安装设置 📦

确保安装依赖：

```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install

# bun
bun install
```

## 开发服务器 👨‍💻

在 `http://localhost:3000` 启动开发服务器：

```bash
# npm
npm run dev

# pnpm
pnpm run dev

# yarn
yarn dev

# bun
bun run dev
```

## 生产环境 🚀

构建生产环境应用：

```bash
# npm
npm run build

# pnpm
pnpm run build

# yarn
yarn build

# bun
bun run build
```

本地预览生产构建：

```bash
# npm
npm run preview

# pnpm
pnpm run preview

# yarn
yarn preview

# bun
bun run preview
```

## 使用 OpenSpec 开发 🚀

本项目使用 OpenSpec 进行文档和开发工作流管理。在与 agents 对话时，使用 `openspec-propose` 技能以享受 SDD（规范驱动开发）工作流：

- **提出变更**：在与 agents 的对话中使用 `openspec-propose` 技能
- **遵循工作流**：agents 将引导您完成规范驱动的开发过程
- **确保质量**：OpenSpec 有助于维护清晰的文档和结构化的开发

查看 [OpenSpec 文档](https://openspec.dev) 获取更多信息。

查看 [Nuxt 3 文档](https://nuxt.com/docs/getting-started/introduction) 获取更多关于框架的信息。
