## ADDED Requirements

### Requirement: Chinese agents.md
The system SHALL provide a Chinese version of agents.md that includes an index of project documentation.

#### Scenario: Chinese-speaking developer accesses documentation
- **WHEN** a Chinese-speaking developer accesses the project documentation
- **THEN** they can refer to the Chinese agents.md for an overview and links to detailed documentation

### Requirement: English agents.md
The system SHALL provide an English version of agents.md that includes an index of project documentation.

#### Scenario: English-speaking developer accesses documentation
- **WHEN** an English-speaking developer accesses the project documentation
- **THEN** they can refer to the English agents.md for an overview and links to detailed documentation

### Requirement: Documentation index structure
The agents.md files SHALL include a clear index structure with links to detailed documentation.

#### Scenario: Developer needs specific documentation
- **WHEN** a developer needs specific documentation
- **THEN** they can use the index in agents.md to quickly find and access the relevant documentation
