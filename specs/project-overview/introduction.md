# 项目简介

## 项目概述

这是一个使用 Nuxt 3、Vue 3 和 Element Plus 构建的个人主页项目。它展示个人信息、项目、技能和博客文章，为访问者提供一个全面了解个人专业背景的平台。

## 主要功能

- **个人信息展示**：展示个人基本信息、教育背景和工作经历
- **项目展示**：展示个人参与的项目，包括项目描述、技术栈和链接
- **技能展示**：展示个人掌握的技能和技术栈
- **博客功能**：展示个人博客文章，分享技术心得和经验
- **响应式设计**：适配不同设备屏幕，提供良好的用户体验

## 技术特点

- **现代前端技术**：使用 Nuxt 3、Vue 3 和 TypeScript 构建
- **组件化开发**：使用 Element Plus 组件库，实现模块化开发
- **状态管理**：使用 Pinia 进行状态管理
- **国际化支持**：支持中英文双语
- **深色模式**：支持浅色和深色主题切换

## 项目目标

- 提供一个专业的个人展示平台
- 展示个人技术能力和项目经验
- 分享技术知识和心得
- 建立个人品牌形象
