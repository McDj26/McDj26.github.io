# 首页功能

## 首页结构

首页由以下几个主要部分组成：

1. **背景图片**：自适应屏幕大小的背景图片，支持白天和黑夜模式
2. **个人信息板**：展示个人基本信息、头像和简介
3. **关于我**：详细介绍个人背景、技能和经验
4. **项目展示**：展示个人参与的项目，包括项目描述和链接
5. **博客文章**：展示个人博客文章，分享技术心得
6. **技能展示**：以可视化方式展示个人技能水平

## 核心功能

### 背景图片切换
- 根据系统颜色模式自动切换白天/黑夜背景
- 响应式设计，适配不同屏幕尺寸
- 平滑的过渡效果

### 个人信息展示
- 显示个人头像、姓名、职位和简介
- 提供社交媒体链接
- 支持个人信息的动态更新

### 页面滚动效果
- 段落式滚动，每个部分占满屏幕
- 滚动时的视差效果
- 滚动到特定部分时的动画效果

### 响应式设计
- 适配桌面、平板和移动设备
- 在不同屏幕尺寸下优化布局
- 触摸设备的交互优化

## 技术实现

### 组件结构

```
pages/home/index.vue
├── BgImage.vue         # 背景图片组件
├── Board.vue           # 个人信息板组件
├── About.vue           # 关于我组件
├── Projects.vue        # 项目展示组件
├── Blogs.vue           # 博客文章组件
└── Skills.vue          # 技能展示组件
```

### 关键技术

#### 背景图片切换
- 使用 `@nuxtjs/color-mode` 管理颜色模式
- 根据颜色模式动态加载不同的背景图片
- 使用 CSS 媒体查询适配不同屏幕尺寸

#### 页面滚动控制
- 使用自定义的 `useSection` 组合式函数实现段落式滚动
- 监听滚动事件，触发相应的动画效果
- 使用 `IntersectionObserver` 检测元素是否进入视口

#### 响应式设计
- 使用 CSS 媒体查询和弹性布局
- 组件内部根据屏幕尺寸调整布局
- 图片使用响应式尺寸

## 交互流程

1. **页面加载**：加载背景图片和个人信息
2. **滚动导航**：用户滚动页面，触发段落式滚动效果
3. **模块交互**：用户与各个模块进行交互，如点击项目链接、查看博客文章
4. **主题切换**：用户切换系统主题，背景图片和界面颜色随之变化

## 性能优化

- 图片懒加载，减少初始加载时间
- 组件懒加载，提高页面加载速度
- 优化动画效果，避免性能问题
- 使用 WebP 格式图片，减小文件大小
