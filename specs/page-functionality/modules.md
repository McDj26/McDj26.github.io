# 功能模块

## 背景模块

### 功能描述
- 展示自适应屏幕大小的背景图片
- 支持白天和黑夜模式切换
- 提供响应式图片加载

### 技术实现
- 使用 `@nuxtjs/color-mode` 管理颜色模式
- 根据颜色模式动态加载不同的背景图片
- 使用 CSS 媒体查询适配不同屏幕尺寸
- 实现平滑的背景切换效果

### 配置
- 背景图片路径：`public/images/`
- 白天模式图片：`day-*.webp`
- 黑夜模式图片：`night-*.webp`

## 页面滚动模块

### 功能描述
- 实现段落式滚动效果
- 滚动时的视差效果
- 滚动到特定部分时的动画效果

### 技术实现
- 使用自定义的 `useSection` 组合式函数
- 监听滚动事件，触发相应的动画效果
- 使用 `IntersectionObserver` 检测元素是否进入视口

### 配置
- 滚动速度：可在 `useSection` 函数中调整
- 动画效果：可在组件中配置

## 主题切换模块

### 功能描述
- 支持白天和黑夜模式切换
- 保存用户主题偏好
- 背景图片和界面颜色随之变化

### 技术实现
- 使用 `@nuxtjs/color-mode` 管理颜色模式

- 动态加载不同主题的样式

### 配置
- 主题切换按钮：可在组件中添加
- 默认主题：可在 `nuxt.config.ts` 中配置

## 搜索功能模块

### 功能描述
- 提供站点搜索功能
- 支持关键词搜索
- 显示搜索结果

### 技术实现
- 使用 `@nuxtjs/algolia` 集成 Algolia 搜索
- 使用 `@docsearch/css` 和 `@docsearch/js` 提供搜索界面
- 配置 Algolia 索引

### 配置
- Algolia API 密钥：在 `.env` 文件中配置
- 索引名称：在 `nuxt.config.ts` 中配置

## 国际化模块

### 功能描述
- 支持中英文双语
- 动态切换语言
- 保存用户语言偏好

### 技术实现
- 使用 `@nuxtjs/i18n` 管理国际化
- 本地存储保存用户语言偏好
- 提供语言切换按钮

### 配置
- 语言文件：在 `assets/i18n/` 目录中配置
- 默认语言：可在 `nuxt.config.ts` 中配置
